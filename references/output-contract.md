# 输出契约 v1

仅核对产物时读取。最终目录恰好包含 final.csv、review_queue.csv、ledger.json。两个 CSV 均为 UTF-8 BOM、标准引号转义、CRLF，分别从1连续编号：

```text
序号,项目名称,项目编号,标段名称,标段编号,公司名称,中标与否,投标排名,文件类别,依据文件路径,来源页码,提取方式,证据文本,置信度,复核状态,解析结果生成日期时间
```

业务值有则填、无则空，不补造官方编号、标段或排名。类别 excel_ledger、提取方式“台账整理”、来源为原文件名、页码空、时间为带时区 ISO 8601。正常提取记录（含待复核）置信度1.0；无法形成 final 的独立问题行0.0，均不表示工商身份概率。

存在投标列时，公司名称只能取对应投标字段。清理全半角、空白、折行及完整企业后缀后的“投标”附注，不纠正错字、重复地名或异常后缀，不用中标名称覆盖。只有中标列的表仍按 award_company 角色保留原记录，不虚构投标来源。

先按项目块、标段及组边界分组。auto 检查原单元格结构：单企业行、中标格不跨行合并、不含名单、不重复展示、且不是所有行都填中标信息时，须有同行精确名称、法人和金额同时对应，或唯一金额加足够名称主体相似度支持，才采用同行对应。中标名精确对应其他行时转组内匹配。显式 row_aligned 只用于已确认的行对应结构，仍执行列表、合并、重复及跨行冲突检查。

组内匹配顺序为精确名称、唯一法人加金额、足够高且明显领先的名称相似度。通用组织/行业词仅比较时降权；输出不变。默认全文相似度≥0.80、去通用词相似度≥0.75、加权分≥0.85、领先第二名≥0.10；前缀省略候选另要求保留至少2字主体、全文≥0.90、加权分领先≥0.15。法人不同不单独否定对应。两条中标名竞争同一投标记录、名称和辅助证据指向不同企业或并列候选时保留复核，不强取最高分。

金额用十进制比较，识别值内及表头的元/万元/亿元；一侧未标单位时沿用另一侧，并在组审计注明。缺失、占位或零金额不作为自动对应依据。名单格包含多家中标企业时，不把一个总金额或法人分配给每家。

明确对应填“是”；本组结果完整且无未解决名称或中标读取异常时，其余企业填“否”。无结果留空。原“是否中标”可映射；与匹配结果冲突留空并复核。“未招投标”备注不独立触发复核，也不覆盖原表明确结果。项目汇总仅作审计，不增加记录或把名单传给子组。

组内重复明细保留全部来源；不同项目/组的参与记录不全局删除。review 复制待复核行，仅重编号并在证据前加原因和换行；独立问题可另列。没有复核时保留表头；两个 CSV 都无记录则失败。

ledger 保存 sources、mapping、matching_policy、projects/groups、records、issues、row_audit、summary、unique_companies 和 CSV 哈希。groups.award_matching 解释结构选择，groups.award_matches 保存原中标名、原单元格、选中的投标记录/名称、依据、候选得分与状态。records.corrections 只记录清洗，不记录公司全称纠正；原始值在 occurrences.raw_values/raw_company。内部 ID 不是官方编号。

unique_companies 从 final 非空公司名按 NFKC、去空白、casefold 去重，保持首次顺序，包含待复核名称；不是已确认工商实体数。CSV 公式形文本加单引号并保存可恢复记录。发布前自动检查名称来源、匹配归属、表头、统计、哈希和复核关联，整批发布到空/新目录。

1.4 不再生成 name_pairs/name_decisions 或名称交接状态，直接 run 至 result；既有1.3产物仍可 validate。1.3未完成任务须用旧版继续，或用新版 run 到新目录，不套用旧决定、不覆盖旧结果。可选 --progress 仅是阶段日志，不规定宿主计划。采集接入见 [名单契约](spider-contract.md)。
